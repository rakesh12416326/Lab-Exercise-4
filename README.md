Aim:
To design a wireframe/prototype for a generic online shopping application using Figma, including essential screens such as Welcome/Splash, Login/Signup, Home/Dashboard, Product Listing, and Checkout/Final Action, with a clear layout structure and navigation flow

Algorithm:
Identify the basic requirements of an online shopping application.
Create a new project in Figma.
Create a mobile frame for the application.
Design the Welcome/Splash Screen with the ShopEase logo and application name.
Design the Login/Signup Screen with email, password, and login options.
Design the Home/Dashboard Screen with a search bar, categories, products, and navigation bar.
Design the Product Listing Screen with product images, names, prices, and cart options.
Design the Checkout/Final Action Screen with delivery details, payment method, order summary, and Place Order button.
Arrange all screens in the correct order.
Use Figma's Prototype feature to connect the screens.
Define interactions such as button clicks, navigation, and page transitions.
Test the complete navigation flow from the Splash Screen to the Checkout Screen.
Check the design for proper alignment, spacing, consistency, and usability.
Make the necessary corrections and save the final prototype.
